Análisis de correspondencia

Contenido visto en clase y herramientas utilizadas para crear la web.

Contenido ya estudiado Contenido nuevo y función
Etiquetas de encabezado: h1, h2 y h3. CSS minificado: elimina espacios, saltos de línea y comentarios para que el archivo pese menos y cargue más rápido.
Párrafos con la etiqueta <p>. Vite: herramienta que crea un servidor de desarrollo y prepara el proyecto para publicarlo.
Enlaces con la etiqueta <a>. Node.js y npm: permiten ejecutar comandos y administrar las dependencias del proyecto.
Listas y tablas en HTML. package.json: registra la información del proyecto y los comandos para desarrollarlo, validarlo o generar la versión final.
Uso de clases para aplicar estilos CSS. Bootstrap: biblioteca de estilos y componentes que ayuda a construir diseños adaptables con menos código propio.
Selectores de clase en CSS. Atributos data-*: guardan datos personalizados en HTML para que JavaScript los pueda leer y usar.
Modelo de caja: margen, borde y relleno. Variables CSS (por ejemplo, --color): guardan valores reutilizables para mantener colores y medidas consistentes.
Colores, tamaños de letra y fondos en CSS. CSS Grid y Flexbox: distribuyen elementos en filas, columnas y espacios de forma más flexible.
Enlazar una hoja de estilos externa. JavaScript con querySelector y classList: selecciona elementos y cambia sus clases para crear interacción en la página.
Etiquetas de texto y enlaces HTML. Eventos de JavaScript (click y submit): responden a acciones del usuario, como abrir un menú o enviar un formulario.
