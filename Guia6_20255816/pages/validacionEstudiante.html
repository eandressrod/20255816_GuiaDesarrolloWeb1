Investigación

¿Qué es una expresión regular?

Una expresión regular es un patrón que describe un conjunto de cadenas de texto. En JavaScript son objetos de tipo RegExp y sirven para comprobar si un texto tiene un formato válido, buscar partes de un texto o reemplazarlas.

Formas de crearla

Existen dos formas equivalentes:

// Literal: el patrón va entre barras
const carnet = /^[A-Z]{2}\d{3}$/;

// Constructor: útil cuando el patrón se arma a partir de un texto
const carnet2 = new RegExp("^[A-Z]{2}\\d{3}$");

Métodos más utilizados

regex.test(texto)
Devuelve true o false si el texto cumple el patrón. Es el que se usa para validar.
texto.match(regex)
Devuelve las coincidencias encontradas, o null si no hay ninguna.
texto.replace(regex, nuevo)
Reemplaza las partes del texto que coinciden con el patrón.

Símbolos básicos

Símbolo Significado
^ y $Inicio y final del texto. Obligan a que todo el valor cumpla el patrón.
\dUn dígito del 0 al 9.
[A-Z]Un carácter dentro del rango indicado.
{n} / {n,m}Exactamente n repeticiones, o entre n y m.
+ / * / ?Una o más, cero o más, cero o una repetición.
( ) y |Agrupar partes del patrón y elegir entre alternativas.
\sUn espacio en blanco.
Banderas i, g, uIgnorar mayúsculas, buscar todas las coincidencias y soportar Unicode (letras con tilde).

Patrones usados en la ficha

Carnet
/^[A-Z]{2}\d{3}$/i: dos letras y tres números (AB001).
Nombre completo
/^[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+(\s[A-Za-zÁÉÍÓÚÜÑáéíóúüñ]+)+$/: solo letras, al menos dos palabras.
DUI
/^\d{8}-\d$/: ########-#.
NIT
/^\d{4}-\d{6}-\d{3}-\d$/: ####-######-###-#.
Fecha de nacimiento
/^(\d{2})\/(\d{2})\/(\d{4})$/: DD/MM/AAAA, y además se comprueba que la fecha exista.
Correo electrónico
/^[\w.+-]+@[\w-]+(\.[\w-]+)*\.[A-Za-z]{2,}$/: usuario, arroba y dominio.
Edad
/^\d+$/: solo números.
